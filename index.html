Assignment 4: Hardware Evaluation Page

Related Chapter: Chapter 3 - Evaluating Hardware

Objective: Evaluate common computer hardware components.

Deliverable: Comparison Table

Component Description Importance
CPU Central Processing Unit. The primary component of a computer that acts as its "brain." Determines overall processing speed and how fast tasks and instructions are executed.
RAM Random Access Memory. High-speed, temporary volatile data storage. Allows for smooth multitasking and efficient short-term data access by the processor.
SSD Solid State Drive. Modern, high-speed non-volatile permanent storage. Significantly speeds up system boot times, software launches, and file transfers.
GPU Graphics Processing Unit. A specialized processor designed to accelerate graphics rendering. Crucial for handling visual assets, high-definition displays, 3D rendering, and AI computing tasks.
